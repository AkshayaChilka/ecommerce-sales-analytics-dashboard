# E-Commerce Sales Analytics & Forecasting Dashboard

## Project Overview
This project analyzes E-Commerce sales performance using Python, SQL, Excel, and Power BI.

The dashboard focuses on:
- Sales and revenue analysis
- Customer and order intelligence
- Geographic performance analysis
- Sales forecasting and business outlook
- Strategic recommendations

## Tools Used
- Python
- SQL (MySQL)
- Excel
- Power BI

## Project Workflow
1. Data cleaning and preprocessing using Python
2. SQL database creation and KPI analysis
3. Interactive Power BI dashboard development
4. Revenue forecasting using Power BI analytics

## Dashboard Pages
1. Retail Sales & Customer Intelligence Dashboard
2. Geographic & Order Intelligence Dashboard
3. Sales Forecasting & Predictive Analytics Dashboard

## Key Insights
- Set category contributes highest revenue
- Bengaluru is the top revenue-generating city
- Cancellation rate identified as an operational risk
- Revenue forecast indicates stable short-term growth
